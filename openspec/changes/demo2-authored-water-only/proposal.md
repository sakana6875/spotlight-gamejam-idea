# Demo2 手工水道行内水平流动提案

## 背景

Demo2 场景在 `WaterInteriorTilemap` 中手工铺设了两行起始水道。旧实现正确地让这两行水按流动步向右扩展，但在遇到阻挡时还会调用 `RaiseWaterBeforeBarrier` 向上一行蓄积，因此进入 PlayMode 后出现了场景未搭建的第三条水道。

此前将整个 `TerrainWaterModel.Step()` 和 Tilemap 写回删除，误伤了用户确认正确的“每步向右一格”效果。本 Change 现在修正为：恢复两条水道各自的水平逐格流动，只删除跨行向上生成水格的规则。

## 目标

1. 保留两条手工起始水道分别按固定步长向右扩展一格的效果。
2. 水只能停留在手工水道起始行，不得向上或向下生成第三行。
3. 保留地面横向边界、SideWallTilemap 和移动 Collider2D 的水平阻挡。
4. 保留水纹动画和实际占水格内的 Rigidbody2D 速度阻尼。
5. 障碍物移开后，原水道行内的水可以继续向右流动。

## 范围

- 恢复有界 `TerrainWaterModel`、流动步长和 Tilemap 逐格写回。
- 删除 `RaiseWaterBeforeBarrier` 及全部跨行蓄积行为。
- 模拟高度严格等于手工水源包围范围的行数；当前场景为两行。
- 恢复 GroundTilemap、SideWallTilemap、移动阻挡和 Wave Tile 引用。
- 更新模型、渲染器、控制器和相关 OpenSpec 合同。

## 非目标

- 不允许在手工起始水道行之外新增水格。
- 不实现向上蓄积、向下落水、瀑布、完整压力传播、浮力或推力。
- 不修改场景中现有两行手工水 Tile 的坐标。
- 不修改玩家推动、视图切换、场景加载或其他 Demo。

## 主要决策

- `sourceBounds.yMin..yMax` 定义允许存在水的固定行集合；地面只延长横向宽度，不再扩大模拟高度。
- `TerrainWaterModel.Step()` 对每一行独立执行“当前水格 → 右侧一格”；右侧受阻时停止，不调用跨行逻辑。
- 手工 Tile 保持永久源格；扩展格仍使用既有 `Wave.asset` 写入同一 WaterInteriorTilemap。
- 每个物理步重采样地面、墙体和移动障碍，因此移开箱子后可继续水平流动。

## 风险

- 当前两行手工水格都被视为永久源格；关卡调整水道行数时，模拟行数会随手工源格包围范围变化。
- 同一手工包围范围内若包含空行，该空行仍属于模拟高度；场景应保持水道行连续。
