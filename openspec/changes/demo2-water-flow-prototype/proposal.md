# Demo2 固定行水平水流提案

## 背景

原型已验证两条手工水道逐格向右推进的效果。问题来自障碍前向上蓄积：`RaiseWaterBeforeBarrier` 会写入 `row + 1`，且 GroundTilemap 最高行曾扩大模型高度，因此场景两条水道可能生成第三条。

## 当前决策

- 保留两条手工源水道按流动步向右扩展。
- 模拟高度严格等于手工水源包围范围高度。
- 删除向上蓄积、越障和所有跨行生成。
- 保留地面横向边界、墙体和移动 Collider2D 阻挡。
- 保留 Wave 动画和实际占水格阻尼。

## 非目标

不实现第三条水道、向下流动、瀑布、浮力或推力。详细合同以 `demo2-authored-water-only` 的修正版文档为准。
