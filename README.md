# 诶？我有个点子！

> 聚光灯游戏开发大赛参赛作品

## 项目简介

《诶？我有个点子！》是一款正在开发中的 Unity 游戏，参加**聚光灯游戏开发大赛**，参赛主题为：

> **涌现**

游戏以一个游戏制作小组的头脑风暴为背景。

玩家将进入制作组的头脑风暴场景，观察一群正在讨论游戏创意的开发者，并与他们进行交流。随着头脑风暴不断推进，玩家将逐渐体验制作组提出的不同游戏构想。

不同创意之间相互碰撞、组合和变化，最终形成一个出乎所有人预料的混乱融合版本。玩家需要完成最终 Demo，击败其中的怪物并成功通关。

在故事结尾，制作组成员从争论和分歧中重新达成和解。队长意识到，与其继续争论，不如把这次头脑风暴本身制作成一款游戏。

## 主题诠释

本项目尝试从“创意如何产生和变化”的角度诠释“涌现”。

一个想法可能来自个人灵感，也可能来自多人交流。当不同成员的观点发生碰撞时，新的内容会不断产生，并逐渐超出最初的预期。

游戏中的不同 Demo、制作组成员之间的交流与分歧，以及最后融合形成的混乱版本，共同构成了一个从讨论、碰撞到新创意诞生的过程。

## 游戏流程概览

1. 玩家进入游戏制作小组的头脑风暴场景。
2. 玩家与制作组成员交流，了解他们提出的不同想法。
3. 玩家体验制作组构思出的多个游戏 Demo。
4. 制作组成员因为创意方向产生分歧并发生争论。
5. 不同创意相互融合，形成混乱的最终 Demo。
6. 玩家在最终 Demo 中击败怪物并完成挑战。
7. 制作组成员和解，并决定将这次头脑风暴制作成真正的游戏。
